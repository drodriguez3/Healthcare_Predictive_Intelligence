# IronGate Healthcare Predictive Intelligence V3
Independent synthetic demonstration prepared for Central Health. Not clinical software or a live Snowflake integration.

Run `python -m pip install -r requirements.txt` then `python -m streamlit run app.py`. CSV and JSON data are included; no credentials needed. To regenerate deterministic data run `python generate_data.py`. Models train once per Streamlit process and are cached; no serialized model dependencies. Deploy app.py to Streamlit Community Cloud using Python 3.12.

Data: patients, claims, encounters, admissions, care coordination, outcomes (one row per synthetic patient; historical aggregates, not individual claim lines), community resources and fictional policies. All predictors represent baseline information; outcomes represent simulated subsequent 30-day events. Readmission is only modeled for recent discharges. Three logistic regressions share a patient-level 70/30 split; only held-out records appear in the demo. Metrics are synthetic, not clinical evidence. Subgroup metrics are descriptive and do not establish fairness. Threshold is illustrative, not a clinical cutoff. Repeat ED is not equivalent to avoidable ED. Resources require human verification. No live Cortex or generative AI. No patient outcome improvement has been demonstrated. Procurement status and communication restrictions must be checked before outreach.

V3 simplifies navigation to three business solutions plus technology and validation. The default copilot demonstrates Predict → Understand → Act. Question routing supports limited keywords and explicit scope filters, not a live LLM. Patient explanations are exact coefficient × feature contributions to log odds relative to zero inputs, not causal or SHAP explanations. Comprehensive intervention tracking is deferred.
